Reference RO types

Each confirmed entry is assigned to the reference type whose profile scores highest, by bit score rather than E-value. One row is one characterised enzyme type.

Click any column header to sort it; click again to reverse. The filter box matches anything in a row, and the chips narrow the table to one RO group, substrate class or literature confidence. Percentages are shares of that type's own members, so they are comparable down a column but not additive. A type with a low β, ferredoxin or reductase share is one whose partners are usually encoded elsewhere in the genome, not one that works without them.
