How much is actually known about each member

Profile assignment answers one question: which characterised enzyme does this protein resemble most? It does not answer the question users care about, which is what the protein does. This page quantifies the gap between the two, so that every substrate label in the database can be read with the right amount of confidence.

The claim above rests on one example. Tested across all {{ pred.pairs_with_both_substrates_known|fmt }} reference pairs whose substrates are both known, the rule "if two proteins are more than X % identical they act on the same substrate" performs as follows. Only {{ '%.1f %%' % (100 * pred.exact_substrate.prevalence) }} of pairs share a substrate to begin with, so precision has to be read against that base rate; the lift column does that.

At the coarser level of substrate class

One might expect the broad class, xenobiotic against natural, to be more predictable. It is not, and the reason is instructive: {{ '%.0f %%' % (100 * pred.substrate_class.prevalence) }} of pairs already share a class because most characterised enzymes act on xenobiotics. Precision therefore looks excellent at every threshold while the lift never exceeds {{ '%.1f×' % (pred.substrate_class.curve | map(attribute='lift') | reject('none') | list | max) }}, so the threshold is adding almost nothing.
