What counts as a genus here, and what is left out

A genus is read from the NCBI taxonomy rank of the genome record that carries the entry: the nearest ancestor whose rank is exactly genus. It is not taken from the first word of the organism name. That difference is measured, not cosmetic: the first word merges every Candidatus organism into one bucket that actually holds {{ gtax.candidatus_genera if gtax and gtax.candidatus_genera else 17 }} separate genera, it carries over quoting and bracketing from the source string ('Nostoc, [Enterobacter]), and it misses renamings {% if gtax and gtax.genus_change %}— {{ '{:,}'.format(gtax.genus_change.entries_whose_genus_changes) }} confirmed entries change genus when the rank is used{% endif %} (Sinorhizobium → Ensifer, Rhizobium rhizogenes → Martinezella).

What is left out of every genus count on this page. {% if gtax and gtax.genus_unassigned %}{{ '{:,}'.format(gtax.genus_unassigned.entries) }} confirmed entries ({{ '%.1f'|format(gtax.genus_unassigned.share * 100) }}%){% else %}614 confirmed entries (3.2%){% endif %} have no genus-rank ancestor at all in the current NCBI taxonomy. The largest case is Mycolicibacterium, which the organism strings still name and which would be this database's seventh largest “genus”: NCBI now holds it as a subgenus, Mycobacterium (subgen. Mycolicibacterium), and that lineage runs from species straight to the family. Those entries are neither dropped nor given an invented genus; they are carried with the state unassigned and the nearest named rank beside them, and they are excluded from the genus counts shown here. The taxonomy page gives the full measurement.
