The member count on this page is not fully determined by biology. The reference sequence of NdmC occurs exactly inside this one, so that record is a fragment of this one and the two should not be counted as separate enzymes.
This is a known defect of the curated reference set, not of the assignment method. It is measured and listed on the data quality page.
Most members of this type are closer to a different reference enzyme. Membership is decided by profile score, while "nearest reference" is measured by sequence identity, and the two are different questions. Here they disagree: of 15 members, only 1 (7 %) are in fact most similar to this type's own reference, and the average identity to the nearest reference is 47.4 %. At that identity no profile can separate the neighbouring types reliably, so read this as a region of sequence space rather than as a set of proteins like the reference.
