Statistical inferences

Each association below is stated as a question, tested, given an explicit verdict, and then opened up, because a single p value for a whole table hides where the association actually lives. Effect sizes are reported alongside every p value: with 19,125 alpha subunits almost any difference reaches significance while only some are large enough to matter.

Entries are not independent observations. Sequence databases contain many near-identical strains of the same species, so treating each alpha subunit as one sample inflates the effective sample size. Where the design allows it, every test is therefore repeated after collapsing the data to one observation per distinct sequence and once more per type and genus. A finding is called robust only if all three levels agree in direction and the genus level stays significant.
A verdict on a table is not a verdict on every row in it. A chi-squared test answers one question — is there any association anywhere in this table — and that question misleads in both directions. An association can be absent overall and still be real and strong inside a single enzyme type or a single reaction class; and it can be present overall while coming entirely from one row, so that “the groups differ” is false for all the others. Every contingency test on this page is therefore resolved twice more: each cell gets a standardised residual, and each row is tested against the sum of the remaining rows. Both families are corrected with Benjamini–Hochberg, and a cell is reported only if it is also material — at least ten percentage points away from the overall rate — and, wherever a genus-level table could be built, only if it survives there too.
