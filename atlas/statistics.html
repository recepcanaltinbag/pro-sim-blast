Statistical inferences

Each association below is stated as a question, tested, given an explicit verdict, and then opened up, because a single p value for a whole table hides where the association actually lives. Effect sizes are reported alongside every p value: with 21,046 alpha subunits almost any difference reaches significance while only some are large enough to matter.

Entries are not independent observations. Sequence databases contain many near-identical strains of the same species, so treating each alpha subunit as one sample inflates the effective sample size. Where the design allows it, every test is therefore repeated after collapsing the data to one observation per distinct sequence and once more per type and genus. A finding is called robust only if all three levels agree in direction and the genus level stays significant.
A verdict on a table is not a verdict on every row in it. A chi-squared test answers one question — is there any association anywhere in this table — and that question misleads in both directions. An association can be absent overall and still be real and strong inside a single enzyme type or a single reaction class; and it can be present overall while coming entirely from one row, so that “the groups differ” is false for all the others. Every contingency test on this page is therefore resolved twice more: each cell gets a standardised residual, and each row is tested against the sum of the remaining rows. Both families are corrected with Benjamini–Hochberg, and a cell is reported only if it is also material — at least ten percentage points away from the overall rate — and, wherever a genus-level table could be built, only if it survives there too.

What counts as a genus here, and what is left out

A genus is read from the NCBI taxonomy rank of the genome record that carries the entry: the nearest ancestor whose rank is exactly genus. It is not taken from the first word of the organism name. That difference is measured, not cosmetic: the first word merges every Candidatus organism into one bucket that actually holds 17 separate genera, it carries over quoting and bracketing from the source string ('Nostoc, [Enterobacter]), and it misses renamings — 360 confirmed entries change genus when the rank is used (Sinorhizobium → Ensifer, Rhizobium rhizogenes → Martinezella).

What is left out of every genus count on this page. 867 confirmed entries (4.1%) have no genus-rank ancestor at all in the current NCBI taxonomy. The largest case is Mycolicibacterium, which the organism strings still name and which would be this database's seventh largest “genus”: NCBI now holds it as a subgenus, Mycobacterium (subgen. Mycolicibacterium), and that lineage runs from species straight to the family. Those entries are neither dropped nor given an invented genus; they are carried with the state unassigned and the nearest named rank beside them, and they are excluded from the genus counts shown here. All tests are computed by stats_overview.py from the database and written to a single JSON file, which this page renders without further arithmetic. The cell-level signal maps, the row-against-the-rest tests and the Benjamini–Hochberg correction live in that same file, so nothing on this page is arithmetic the template invented.
