How much is actually known about each member

Profile assignment answers one question: which characterised enzyme does this protein resemble most? It does not answer the question users care about, which is what the protein does. This page quantifies the gap between the two, so that every substrate label in the database can be read with the right amount of confidence.

2 · Why the levels are about enzyme type, not substrate

Among the characterised references themselves, the most similar pair with different substrates is 1_114_NdmB and 1_115_NdmC at 100.0 % identity (caffeine against 7-methylxanthine), while the least similar pair that shares a substrate is 3_301_PhnA1a and 3_319_PhdA at 32.4 %. 65 of 964 reference pairs with different substrates exceed 60 % identity. No global identity cut-off can therefore certify a substrate in this family; specificity is set by a few active-site positions. The levels above express confidence that two proteins are the same kind of enzyme, which is a weaker and defensible claim. See the full calibration table

3 · How well does identity actually predict the substrate?

The claim above rests on one example. Tested across all 992 reference pairs whose substrates are both known, the rule "if two proteins are more than X % identical they act on the same substrate" performs as follows. Only 2.8 % of pairs share a substrate to begin with, so precision has to be read against that base rate; the lift column does that.

At the coarser level of substrate class

One might expect the broad class, xenobiotic against natural, to be more predictable. It is not, and the reason is instructive: 82 % of pairs already share a class because most characterised enzymes act on xenobiotics. Precision therefore looks excellent at every threshold while the lift never exceeds 1.2×, so the threshold is adding almost nothing. The area under the curve, 0.685, is the honest summary. 7 · When the profile and the nearest sequence disagree

For a share of members the best-scoring profile belongs to one type while the most similar individual reference protein belongs to another. This is expected at low identity, where a profile built from many homologues outscores any single sequence, but it marks pairs of types that are better treated as one lineage.
